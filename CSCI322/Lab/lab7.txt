Task 3: 
Configure NAT on the Server VM

- Configure the Server as a NAT Router
  - Allow your Desktop VM to access the internet through your Server VM.

1. Enable IPv4 packet forwarding on the Server VM: net.ipv4.ip_forward=1
2. Configure IP masquerading using iptables: sudo iptables -t nat -A POSTROUTING -o enp0s8 -j MASQUERADE
3. Make IP forwarding persistent through /etc/sysctl.conf.
4. Install iptables-persistent and save the NAT rules.
5. Test internet connectivity from the Desktop VM using ping.

Task 4:
Configure DNS

We need to update two things:
1. Forward DNS: Map hostnames to the new IP addresses.
2. Reverse DNS: Map the new IP addresses back to hostnames.


Task 5:
Enable port forwarding

Add a port forwarding rule for the VMs 
- This forwards requests from your Mac's port 80 to Apache on your Server VM's port 80.
  - When typed  http://localhost/dokuwiki
  - Port forwarding: VirtualBox forwarded req from your Mac's port 80 to the Server VM's port 80.
  - Apache: Received the HTTP request and served the website
  - DokuWiki: Apache delivered the DokuWiki page to your browser
