2. Capture packets using tcpdump
The server listens for ARP and ICMP packets while the desktop tries to contact it. 
You then examine the captured packets to identify the desktop's MAC address.

2 protocols:
ARP: Finds the MAC address associated with a local IP address
ICMP: Carries messages used by tools such as ping

3.
Open Wireshark on your Desktop VM
- Select and double click the active Ethernet interface, likely enp0s3
- it will start capturing packets
- On your Server VM, ping -c 2 10.0.2.200
- On your Desktop VM, open browser and visit https://www.google.com
- Wait for page to load, then return to Wireshark and click red Stop button
- Save the capture file using File → Save As.
- In Wireshark's display filter bar, enter: icmp
- Find an Echo (ping) request packet and select it. Expand Ethernet II in the Packet Details pane.
- Record these fields:
    - Source MAC address
    - Destination MAC address
    - Packet number 
    - Ping response time (Ping response time: 10.59 ms)
