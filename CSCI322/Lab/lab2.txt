Qn3:
command: 
crontab -l    # list current crontab entries 

output: 
 0 9 * * 1 grep shark /etc/group 2>&1 > /tmp/sharks
- 0 9 * * 1              # scheduling 9.00am every monday
- grep shark /etc/group  # searches /etc/group for lines containing shark.
- 2>&1                   # redirects standard error (file descriptor 2) to wherever standard output 
                           (file descriptor 1) currently points which is terminal screen.
- > /tmp/sharks          # redirects standard output (file 1) to /tmp/sharks, overwriting that file but
                           only file 1 get redirects to overwrite file in /tmp/sharks but file 2 stays on terminal screen
