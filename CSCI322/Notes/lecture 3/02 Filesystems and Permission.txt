Absolute vs relative paths

Ex.
/
├── usr
│   ├── bin
│   │   └── ls
│   └── local
│       └── bin

Absolute path:
/usr/bin/ls - always start at the root /

Relative path:
../bin/ls - start from current directory 

A relative path is useful as user dont have to type the whole path while
accessing a file or dir, can just specify the path from current dir
