Shell Commands

$ vs #
Your prompt tells you which user you are operating as
- $ means normal user
- # means root user/admin (have extremely powerful permissions)


Command structure:
command -options arguments

Ex.
ls -l /home
grep -i "hello" file.txt   # 2 args
man -k password   # search for commands related to password


File commands

ls      # list files
ls -l   # list files with detailed info like dates etc

cp (copy files)
cp src.txt dstn.txt     # copy src.txt's content into dstn.txt
cp -r folder1 folder2   # copy everyth in folder 1 into folder2 , -r means recursive
cp file.txt /home/user/ # copy into a directory

mv (move/rename)
mv file.txt /home/user/
mv old.txt new.txt

rm (remove) 
rm file.txt 
rm -r folder   # delete folder and everyth inside it , -r means recursive

***be careful with rm because deleted files generally are deleted perm 

cat (display contents)
cat file.txt 
cat file1.txt file2.txt   # display contents of both files

more (view page by page)
more largefile.txt
ls -l /etc | more   # list contents of /etc in detailed format, one screen at a time)

pwd (print working directory)
pwd

chmod (change file/dir permissions)
chmod +r file.txt   # add read permission
chmod -w file.txt   # remove write permission
chmod +x file.txt   # add execute permission
chmod +x script.sh  # give script.sh execute permission


Useful Text Commands

grep (search text)

grep "Hello" file.txt     # search for hello inside text file
grep -i "hello" file.txt  # -i ignores loweruppercase 
grep -v "Hello" file.txt  # search for lines that does not contain "Hello" inside text file

wc (count)

wc -l file.txt   # count lines
wc -w file.txt   # count words
wc -c file.txt   # count bytes

sort (sort lines)

sort file.txt     # sort alphabetical asc order  
sort -r file.txt  # -reverse, sort alphabetical desc order  
sort -n file.txt  # sort numerical asc order 
sort -nr file.txt  # -numeric reverse, sort numerical desc order 

cut (extract fields)

cut -d: -f2 file.txt  # -delimiter = : , -field = field2 

Ex. 
john:123:student -> 123
mary:456:student -> 456 

diff (compare files)

diff file1.txt file2.txt  # shows differences between 2 files

tr (translate characters)

tr a A < file.txt  # replace every lowercase a with uppercase A in file.txt

n1 (number lines)

n1 file.txt  # displays the file with line numbers


System Commands

who (shows users currently logged in)

w (shows logged in users and what they are currently doing) 

whoami (shows current username)

id (shows ur userID and group info)

uname -a (displays system and kernel info)

***Standard Streams
Every normal UNIX/Linux process has 3 standard streams:

             PROGRAM
            /   |   \
           /    |    \
       stdin  stdout stderr
         0       1      2

stdin = input into a prog (keyboard → program)
stdout = output from a prog (program → terminal)
stderr = error/status output (program → terminal)


Redirection
It changes where a command's input or output goes

> (redirects stdout → file)

ls > result.txt  # save it to result.txt instead of displaying the ouput and will override existing content 

>> (redirects stdout → file)

ls > result.txt  # same as > but append content instead of overwriting it 

2> (redirects stderr → file)

command 2> errors.txt  # normal output stays on the screen while errors go into errors.txt

2>&1 (redirects stderr to same place stdout is currently going)

command > result.txt 2>&1  # both normal output and errors end up in the same file

< (redirects file → stdin)

tr a A < file.txt  # replace every lowercase a with uppercase A in file.txt


Pipes
A pipe connects stdout of 1 command to stdin of another command

command1 | command2 (connect stdout → stdin)

ls | more  # lists files/directories then send the stdout of ls to stdin of more which displays output 1 screen at a time 

cat file.txt | grep "hello" | sort | more  # multiple pipes - each command takes the prev command's output as its input 


Quotes
Control how Bash interprets characters
'$HOME'  # treat things inside single quote as plain text 
"$HOME"  # perserve things inside as 1 unit but still allow variable expansion 
└── /home/john


Backslash \
A backslash tells bash to escape a special character

echo $HOME   # /home/john  
echo \$HOME  # $HOME


Variables
A container for storing value

NAME=john
echo $NAME  # john - $ sign tells bash to expand the var  


Environment Variables
Variables that contain info about the current system/shell environment and 
can be passed down to child processes 

NAME=John
export NAME

Now if Bash starts a child process, that process can access NAME

Common Environment Variables:
HOME, PWD, PATH, SHELL, LOGNAME, TZ 


Bash Scripting
Simply a file containing Bash commands

#!/bin/bash  # Called Shebang - Tells OS this is a script and use bash prog at /bin/hash to interpret it

echo "Hello"
echo "Welcome"

Save as script.sh


Running a Script
Few ways to run a script 

bash script.sh 
chmod +x script.sh then ./script.sh  # the ./ means execute script.sh from current dir


Script Arguments
./script.sh hello world  # 3args -> ./script.sh (1) hello (2) world (3)


Bash if
if lets your script make decisions
- Numbers → -eq, -ne
- Strings → ==, !=

if [ $# -ne 2 ]; then   
    echo "Need 2 arguments"
else
    echo "Correct"
fi                      # end if 


Bash loops 
Loops allows to repeat commands

for x in apple banana orange; do
    echo "$x"
done


while read
Reads the file one line at a time

while read line; do
    echo "$line"
done < file.txt    # makes file.txt become the loop's stdin


Bash Functions
A function is a named group of commands

function hello() {     # define function
    echo "Hello"
}

hello                  # call function 


Local variables
By default, var created inside a function can behave as shell-global var

function hello() {     # define function
    local x = "Hello"
    echo "$x"
}

hello                  # call function 
echo "$x"              # x is not avail outside the function


Bash Arrays
A container for storing multiple values

arr=(apple banana orange)  # starts at index 0 
echo "${arr[0]}"           # apple 
echo "${arr[@]}"           # apple banana orange 
echo "${#arr[@]}"          # 3
