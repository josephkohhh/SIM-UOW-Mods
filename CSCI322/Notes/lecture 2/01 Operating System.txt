What is an OS?
It is an executive manager that manages all of the hardware and software

Types of OS:
- Windows
- UNIX family 
  - Linux
  - MacOS

Accessing a UNIX/LINUX system
- Computer turns on 
- Kernel loads -> Hardware/drivers are initialized
- System services start
- Login / user environment
- Shell
- User enters commands

Kernel = OS core 
Terminal = the place/window where I type commands (interface)
Shell = the program that interprets the commands you type (command interpreter)
