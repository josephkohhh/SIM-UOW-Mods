Networking I

1. OSI Model (7 Layers)
Layer	Name	    Responsibility
7	Application	    Provides network services to users (HTTP, FTP, DNS).
6	Presentation	Handles data formatting, encryption and compression.
5	Session	        Establishes, manages and terminates communication sessions.
4	Transport	    Provides end-to-end delivery using TCP or UDP.
3	Network	        Handles logical addressing and routing using IP.
2	Data Link	    Handles MAC addresses and Ethernet frames.
1	Physical	    Transmits raw bits through cables, fibre or wireless signals.

Layer 1 = Bits
Layer 2 = Frames
Layer 3 = Packets
Layer 4 = Segments (TCP) / Datagrams (UDP)
Layer 5–7 = Application-related functions


2. Encapsulation vs Decapsulation

Encapsulation
Process of adding headers and trailers to data as it travels down the OSI layers

Ex.
When data is sent:
1. Application creates the data.
2. Transport layer adds a TCP/UDP header.
3. Network layer adds an IP header.
4. Data Link layer adds an Ethernet header and trailer.
5. Physical layer transmits the data as bits.

Decapsulation
Process of removing the headers and trailers to recover the original data


3. MAC Address vs IP Address
MAC = Identifies a network interface on the local link.
IP = Identifies a device's network location for routing. 

MAC Address
- Physical (hardware) address 
- Used at layer2 under OSI Model
- 48 Bits
- Ex. 00:1A:2B:3C:4D:5E

IP Address
- Logical address
- Used at layer2 under OSI Model
- IPv4 is 32 bits
- Ex. 192.168.1.10


4. Ethernet
It is used in wired local area networks (LANs).


5. IPv4
IPv4 is an addressing system used to identify devices on an IP network
- uses 32 bits
- divided into 4 octets
- each octet contains 8 bits
- each octet has a decimal value between 0 and 255


An IPv4 address has 2 parts:
- Network portion: Identifies the network  
- Host portion: Identifies a device within that network


Ex. 192.168.1.10/24
- Network address: 192.168.1.0 (0 always reserved for network address)
- Host portion: 10

each octet = 8 1s (128+64+32+16+8+4+2+1=255)
/24 = 3 octets = 255.255.255.0 (subnet mask)

subnet mask tells ur device which devices are in its local network


6. Subnetting
Subnetting means dividing a larger network into smaller networks

To calculate how many usable IP addresses a subnet provides: 

    Usable hosts = 2^h - 2

Ex 1. Given 192.168.1.0/24. Find the number of usable hosts.

Step 1: host bits = 32 − 24 = 8
Step 2: use formula = 2^8 -2 = 254 usable hosts

Ex 2. Given 10.10.0.0/16. Find the number of usable hosts.

Step 1: host bits = 32 − 16 = 16
Step 2: use formula = 2^16 -2 = 65,534 usable hosts

7. Supernetting
Supernetting combines multiple smaller networks into 1 larger network.
It is also called route aggregation or route summarisation.

Ex. Combine 4 network into 1 network

Network	        IP address range
192.168.0.0/24	192.168.0.0 – 192.168.0.255
192.168.1.0/24	192.168.1.0 – 192.168.1.255
192.168.2.0/24	192.168.2.0 – 192.168.2.255
192.168.3.0/24	192.168.3.0 – 192.168.3.255

Each /24 network contains 256 IP addresses
We want to combine all 4 into 1 network.

***Rmb:
1 bit allows 2 networks

So we have 4 networks so 2 bits

Our original prefix is /24, so 24 - 2 = /22 

/22 is 2 octets + 6 bits = 255.255.252.0 (subnet mask)

block size = 256 - 252 = 4 (increments of 4)

Answer:
192.168.0.0/22
Subnet mask: 255.255.252.0
Network range: 192.168.0.0 – 192.168.3.255
Usable hosts: 1022 (32-22=10 , 2^10-2=1022)


Subnetting: Divides 1 large network into smaller networks.
Supernetting: Combines multiple smaller networks into 1 larger network.
