Qn. Write a one-line command to find the most recent GET request for /downloads/courseguide.pdf. Display the hostname and timestamp. 
Ans. awk '$6 == "\"GET" && $7 ~ /^\/courses\/[^/]+$/ {sub(/^\/courses\//, "", $7); print $7}' university_access.log | sort -u > courses.txt

Explanation: 
The awk command checks each log entry for a GET request to /downloads/courseguide.pdf. 
It stores the hostname in field $1 and the timestamp in fields $4 and $5. 
As the log is processed, each matching request replaces the previous match, 
so the command displays the hostname and timestamp of the last matching request in the file. 
This identifies the most recent request if the log entries are in chronological order.
