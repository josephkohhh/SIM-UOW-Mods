setupAccounts.sh


#!/bin/bash

# Create groups if they do not already exist
if ! getent group students > /dev/null; then
    if groupadd students; then
        logger "Created group: students"
    else
        echo "Failed to create group: students"
        exit 1
    fi
fi

if ! getent group tutors > /dev/null; then
    if groupadd tutors; then
        logger "Created group: tutors"
    else
        echo "Failed to create group: tutors"
        exit 1
    fi
fi

# Read Accounts.txt line by line
while IFS=, read -r username account_type || [[ -n "$username" ]]; do

    # Skip empty lines
    [[ -z "$username" ]] && continue

    # Select the correct group
    case "$account_type" in
        student)
            group="students"
            ;;
        tutor)
            group="tutors"
            ;;
        *)
            echo "Invalid account type for $username"
            continue
            ;;
    esac

    # Create the user if they do not already exist
    if ! id "$username" > /dev/null 2>&1; then

        if useradd -m -s /bin/bash -g "$group" "$username"; then
            logger "Created user: $username in group $group"

            # Set the initial password
            if echo "$username:Welcome123" | chpasswd; then
                echo "Created user: $username ($group)"
            else
                logger "Failed to set password for user: $username"
                echo "User created, but password setting failed: $username"
            fi

        else
            echo "Failed to create user: $username"
        fi

    else
        echo "User already exists: $username"
    fi

done < Accounts.txt

    if [[ "$account_type" == "tutor" ]]; then
        echo "$username"
    fi 
done < Accounts.txt > /tmp/tutors.txt

---

1. Read account information

while IFS=, read -r username account_type || [[ -n "$username" ]]; do

The while loop reads Accounts.txt one line at a time. IFS=, sets the comma as the field separator, allowing the username and account type to be stored in separate variables. The additional condition handles a final line that does not end with a newline character.

2. Filter tutor accounts

if [[ "$account_type" == "tutor" ]]; then

The if statement checks whether the account type is tutor. Only users with this account type are selected.

3. Output tutor usernames

echo "$username"

The echo command prints the username of each matching tutor, with each username on a separate line.

4. Read from the input file and save the output

done < Accounts.txt > /tmp/tutors.txt

< Accounts.txt redirects the contents of Accounts.txt into the loop.

> /tmp/tutors.txt redirects the output into /tmp/tutors.txt, creating the file if it does not exist or overwriting it if it already exists.

How to Execute the Script

Run these commands from the directory containing reportTutors.sh and Accounts.txt:

chmod +x reportTutors.sh
bash -n reportTutors.sh
./reportTutors.sh

chmod +x makes the script executable.

bash -n checks for Bash syntax errors without executing the script.

./reportTutors.sh runs the script to generate /tmp/tutors.txt.
