What is Data?
- A piece of info that can be stored electronically
  - text, number, images, audio, etc

Types of Data
- Structured Data
- Unstructured Data 

Structured Data
- Data that has fixed format
  - csv file
- Stored in tables and uses SQL to retrieve data

Unstructured Data
- Data that has no fixed structure
  - Images, Videos, Audio recordings, PDF documents, Social media posts
- Stored as files/documents and uses NoSQL or AI techniques to retrieve data


Big Data
- Refers to datasets too large/complex for traditional db to process efficiently
- Big Data Technologies (ML, AI, Data mining)
- Ex. watches billions of viewing records


What is a Database?
It is an organised collection of data stored electronically

A database contains tables
- rows = records (John, 12, boy)
- columns = attributes (name, age, gender)

Relational Database 
- stores data in related tables
- contains relational tables
  - rows = records (John, 12, boy)
  - columns = attributes (name, age, gender)
- relationships connect tables together
- uses SQL to perform CRUD 
- Ex. PostgresSQL, MS Sql server, Oracle 


Types of Database

NoSQL database

2. Hierarchical Database 
- stores data in a tree structure:
- suited for banking, insurance, telecomm 

Company
│

3. Network Database
- stores data as a network instead of a tree
- suited for universities, airline reservations, supply chains
- 1 student can enrol in many courses
- 1 course contains many students
This is called a many-to-many relationship

   Student
   /    \
Course1 Course2


4. Graph Database
- Stores data as nodes, edges, properties 
- Suited for financial fraud detection 

Node = object
- person, product, bank acc
Edge = relationshio
- John ----Friend---- Mary
Properties = additional info

City = Singapore
