What is Spatial Data?
Spatial data stores the location and shape of real-world objects
- GPS coordinates
- Roads, Buildings, Rivers, Countries, Parks

Unlike normal databases that store only text or numbers,
spatial databases also store where an object is located

3 Types of Spatial Data

1. Point
- Represents a single location using coordinates
- Ex. Taxi location, ATM, Restaurant, Bus stop
- A point is represnted by (x, y) = (10,20)

2. Line 
- A sequence of connected points
- Used for roads, railways, rivers, pipelines
- Ex. A ------- B ------- C

3. Region
- Represents an enclosed area
- County, State, Park, Lake, Shopping mall 
- Usually represented using multiple boundary points


3 Types of Spatial Relationships
Spatial databases can determine relationships between objects

1. Topological Relationships
- Describes how two objects relate
- Keywords: Adjacent, Contains, Intersects

Ex. 
Country contains city
Park intersects road
Two buildings are adjacent


2. Direction Relationships
- Describe relative positions
- Keywords: North of, South of, Above, Below

Ex.
Singapore is south of Malaysia


3. Metric Relationships
- Based on measurable distance

Ex.
Restaurant is within 500 m
Hospital is 2 km away


3 Spatial Query Types
Spatial databases answer location-based questions

1. Window Query
- Window = rectangular search area
- Find all objects inside a rectangle

 Ex.
 Find all cafes in Orchard


 2. Range Query
 - Range = circular search area
 - Find all objects within a distance

Ex. 
Find all ATMs within 500 m


 3. k Nearest Neighbor (kNN)
 - "k" means how many nearest results to return
 - Find the k closest objects from current location

 Ex.
 Find the nearest 3 taxis from my current location


 Spatial Index Structures
 Searching every object is slow. Instead, databases build spatial indexes to speed up queries
 - Quad-tree
 - R-tree

 Quad-tree
 A hierarchical tree. The space is divided into 4 equal regions repeatedly

 Root
+-----+-----+
|     |     |
+-----+-----+
|     |     |
+-----+-----+

Each square can be divided again

Instead of searching every point, search only relevant regions


Search process of Quad-tree:
- Every query has 2 stages
  - Filtering
    - Find tree nodes that might contain the answer, ignore unrelated regions
  - Refinement
    - Check the actual objects inside those regions. Removes false matches



R-tree
- Instead of splitting space equally, It groups nearby objects. 
- Each group is stored inside a Minimum Bounding Rectangle (MBR)

Root
+-------------------------------+
| MBR A | MBR B | MBR C |
+-------------------------------+

Search process of R-tree
- Every query has 2 stages
  - Filtering
    - Visit only the child nodes whose MBRs intersect the query
    - Ignore MBRs that do not overlap with the query, reducing the search space
  - Refinement
    - Check the actual objects inside those MBRs. Removes false matches


*R-tree indexing is generally faster for uneven distribution of nodes
- With a quad-tree:
  - Fixed 4-way division
  - Space is repeatedly divided into 4.
  - You may get many empty or sparsely populated regions. (does region intersect query? prune/search)
  - The tree can become unnecessarily deep.

- With a R-tree:
  - Variable grouping
  - Nearby objects are grouped together into a MBR
  - MBR that dont intersect a query is pruned 
  - Avoids creating unnecessary subdivisions 


Spatial Query Processing — Best-First Search
- BFS is a search strategy used in spatial indexes such as R-trees to find nearest objects first
  
Ex. Nearest Neighbor Query 

Algo cals the minimum possible distance (MINDIST) from point Q to each MBR
MBR A → MINDIST = 20
MBR B → MINDIST = 5 (search B first since MINDSIT is nearest to point Q)

Priority Queue

        MBR B → distance 5   ← explore first
        MBR A → distance 20
        MBR C → distance 35

Process:
1. calc MINDIST of each MBR from point Q
2. put each MBR node in priority queue order by ascending dist
3. remove the 1st node and search that node
4. if couldnt find, repeat the process of 3. until find 

BFS can avoid exploring irrelevant/far-away regions early, making it particularly useful for nearest-neighbor 
and k-nearest-neighbor (k-NN) spatial queries


Spatial-Textual Data 
It stores both location and descriptive text while spatial data only stores location

Ex.

Location: (1.302,103.831), Text: (Japanese, Sushi, Ramen)


What is an Inverted File?
- it is a text index
- instead of storing Document → Words, it stores Word → Documents (faster)

Normal index:
Document → Words

Inverted index:
Word → Documents

Ex.

coffee

Restaurant A that sells coffee
Restaurant B that sells food
Restaurant C that sells coffee


Spatial-Textual Index
Spatial-textual queries must satisfy both Spatial index + Textual index
- IR-tree (Inverted R-tree)
  - Combines R-tree + Inverted File

Search process of IR-tree
- Every query has 2 stages
  - Filtering
    - Visit only the child nodes whose MBRs intersect the query
    - Ignore MBRs that do not overlap with the query, reducing the search space
  - Textual filtering
    - Use inverted index associated with the R-tree nodes to determine 
      whether the relevant objects/nodes contain the keyword such as “sushi.”
  - Refinement
    - Check the actual objects inside those MBRs. Removes false matches
    - Check the actual text to make sure it contains the keyword



Spatial Query Processing — Best-First Search with textual score
- Instead of ranking candidates only by spatial distance, we rank them using a combination of
  - Spatial relevance score (How close is the object?)
  - Textual relevance score (How well does the object match the keywords?)

The higher the score, the better the object
 
                 Root
              /    |    \
             A     B     C
           score  score  score
            0.7    0.9    0.4
                    ↑
               explore first 

Especially useful for queries such as "coffee near me"

Applications of Spatial Computing:
- Taxi Services (Uber, Grab, GoJek)
  - Match passenger with nearest driver 
  - Minimise waiting time

- Food Delivery (GrabFood, Foodpanda)
  - Assign nearest rider
  - Plan efficient delivery routes
