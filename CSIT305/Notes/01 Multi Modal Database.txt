What is Data?
- A piece of info that can be stored electronically
  - text, number, images, audio, etc

Types of Data
- Structured Data
- Unstructured Data 


Structured Data
- Data that has no fixed structure
  - Images, Videos, Audio recordings, PDF documents, Social media posts
- Stored as files/documents and uses NoSQL or AI techniques to retrieve data

Unstructured Data
- Data that has fixed format
  - csv file 
- Stored in tables and uses SQL to retrieve data


Big Data
- Refers to datasets too large/complex for traditional db to process efficiently
- Big Data Technologies (ML, AI, Data mining)
- Ex. watches billions of viewing records
