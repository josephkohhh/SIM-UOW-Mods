Q1. Explain how a blockchain uses hashing to detect tampering.

Every block contains transaction data, a timestamp, its own hash, and the previous block's hash — this chaining is what links blocks 
together. Each hash is a unique digital fingerprint (a 256-bit output) such that even a tiny change in the underlying data produces a completely different hash.

If someone modifies a transaction in an earlier block (e.g., Block 1), that block's hash changes. 
Because Block 2 stores the original hash of Block 1 as its "previous hash," the stored value no longer matches 
Block 1's new hash — creating a mismatch. This invalidates Block 2, and in turn Block 3 and all subsequent blocks, 
since each one's stored "previous hash" was based on the old, unmodified chain. 
The network can therefore detect unauthorized changes and reject the tampered chain, which is how the blockchain enforces immutability.


Q2. Compare Proof of Work (PoW) and Proof of Stake (PoS) as consensus mechanisms. (5 marks)

Proof of Work (PoW) = Bitcoin
- Miners compete to solve mathematical puzzles; first to solve wins
- Winning miner adds the block and receives bitcoins
- Very secure/immutable
- Network is slow and consumes a lot of energy
- Requires Computational power

Proof of Stake (PoS) = Ethereum
- Validators lock up (stake) ETH; the network chooses validators to validate blocks
- Successful validators receive ETH rewards
- Faster and more energy efficient
- Requires staking ETH


Q3. What is a smart contract, and how does it differ from a blockchain? (5 marks)

A smart contract is a program stored on the blockchain that automatically executes when predefined conditions are met — 
for example, an agreement that automatically transfers money once conditions are satisfied, with no bank or lawyer needed. 

A blockchain is a distributed ledger that stores transactions across a network of computers

Its key features are that it is 
- self-executing, 
- autonomous, 
- transparent, 
- immutable, 
and requires no third party. 

Building one involves: parties creating a legal agreement, 
defining every possible condition (e.g., delivery, payment, deadlines), 
coding the contract (e.g., in Solidity), uploading it to the blockchain, 
executing it automatically, and recording the completed transaction permanently.


Q4. Describe the ransomware attack procedure and the two main types of ransomware. (5 marks)

Ransomware is malware that locks or encrypts a victim's system or files and demands payment for recovery. 
It comes in two main forms:
- Cryptographic Ransomware (encrypts files until the ransom is paid)
- Locker Ransomware (locks the UI/OS until payment is made)

The attack procedure
- Initial Access - attacker enter systems via password spraying, stolen cred, phishing attacks, brute force
- Post Exploitation – attacker installs tools like Remote Access Tool (RAT) or other malware.
- Reconnaissance – attacker collects sensitive cred (usernames, passwords)
- Data Theft – attacker steals data.
- Ransomware Deployment – attacker encrypts files or locks the OS and demands payment.


Q5. Compare centralized and decentralized (peer-to-peer) botnet architectures. (5 marks)

A bot is a compromised IoT device (targeted because such devices have small processors, limited memory, and weak security
e.g., smart cameras, smart TVs, sensors), and a botnet is a collection of infected devices used to launch DoS/DDoS attacks 
against a target server.

All bots take instructions from a single C&C server, so if that server is shut down, 
the entire botnet fails — making it easier to disable but simpler to manage/coordinate.

Decentralized (Peer-to-Peer): Bots (Node A, B, C, …) communicate among themselves with no central server,
directing traffic at the victim server. This makes the botnet harder to shut down (no single point of failure) 
but also harder for the attacker to manage and coordinate.


Q6. Explain the role of a Demilitarized Zone (DMZ) in network defense. (5 marks)

A DMZ is a secure buffer network placed between the Internet and an organization's internal network. 
Traffic flows as: Internet → Perimeter Firewall → DMZ → Internal Firewall → LAN.

By placing publicly accessible services in this buffer zone rather than directly on the internal network,
prevents attackers from directly reaching internal systems even if they compromise something in the DMZ.

Its benefits include acting as an extra security layer, enabling better monitoring of traffic passing through, 
and limiting how far an attacker can penetrate if they breach the outer perimeter.
